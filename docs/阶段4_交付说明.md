## 一、各里程碑验收结果（如实标注）

### 4A 虚拟账户与模拟交易（paper_trading.py + 页面 12）— ✅ 已验收
- 账户/持仓/订单全部 SQLite 持久化（重启不丢，有重开连接测试）；账户间数据隔离。
- 市价单成交模型：`close_simplified`（数据集最后已知收盘价 + 滑点 + 手续费），
  订单如实记录参考价与**行情时间戳**；行情过期（>14 天）拒单并说明（演示数据被拒的
  真实记录见下"端到端"）。
- 风控全部落库留痕：负现金/超额卖出/单笔上限/单资产上限/最低现金/单日成交额上限。
- 撤销仅限未成交订单；删除账户需输入账户名二次确认。
- 策略驱动：绑定策略 → 信号评估（只用 ≤t 数据）→ 目标差额下单；
  `signal_id=策略|资产|信号日|目标` 唯一防重复；暂停后零新订单（有测试）。
- 测试 14 个：手算账目、往返平仓净值一致性、防重复、暂停、持久化、过期行情。

### 4B 任务调度（scheduler.py + db 状态机 + 页面 13）— ✅ 已验收
- **统一任务状态**：执行态 `queued→running→(cancel_requested)→succeeded/failed/cancelled`
  + `skipped/missed`；调度配置态 `enabled/paused/disabled/error` 分离管理。
  `db.transition_task` 原子校验非法跳转（终态不可复活，有测试）；旧值 `success`
  只读映射为 `succeeded`（历史记录不改写，有测试）。
- 调度能力：daily/weekly/interval/once、指定时刻、暂停/恢复/停用/立即触发、
  misfire 策略（skip 记 skipped 执行 / catchup_once 补跑）、下次计划时间展示。
- 幂等与单实例：`schedule_id+planned_at` 唯一防同一计划实例重复执行（有测试）；
  调度线程由 `st.cache_resource` 进程内单例 + SQLite 租约（心跳 90s 超时可接管）
  跨进程唯一——页面刷新/切换不重启线程（有租约抢占测试）。
- 处理器注册表：collect/backtest/walk_forward/paper_signal/report 五类可调度，
  复用阶段 1 的 tasks 线程执行与日志机制；重启后 `recover_stale_tasks`
  清理 running/cancel_requested 残留（不留虚假运行中任务）。
- 测试 15 个：时间计算、状态机、幂等、misfire、租约、处理器真实执行。

### 4C PDF 报告（pdf_report.py + 各页导出按钮）— ✅ 已验收
- 三级字体回退：项目字体(data/fonts/*.ttf) → 系统 TTF（simhei 等）→ 内置
  STSong-Light CID；**全部失败抛 PDFFontError 拒绝生成**并给出修复指引与
  HTML/CSV 替代（有注入坏注册表的测试）。
- 三类报告（回测/ML 实验/组合）全部由真实记录生成；matplotlib 中文图表嵌入；
  LongTable 长表自动分页；页脚含页码/生成时间/实验 ID。
- 验证方式（不止检查文件存在）：**pypdf 提取文本**断言中文标题/正文可读、
  报告数字与库中记录一致（如总收益百分比逐字符匹配）、≥2 页分页、
  失败不留半成品文件（有测试）。
- 测试 8 个：字体回退、中文可读性、数字一致性、三类报告、失败降级。

### 4D 均值—方差优化（mvo.py + 组合页集成）— ✅ 已验收
- 三种目标：最小方差 / 目标收益（不可行明确报错，不静默改参）/ 风险厌恶效用；
  约束 0≤w≤cap、**预算约束 Σw=1**（现金由组合层 cash_reserve 控制——初版 Σw≤1
  会退化为全现金，已修正为标准满仓预算约束并加可行性预检 cap×n≥1）。
- 估计口径全显式：日收益均值×252 年化、样本协方差（ddof=1）/可选 Ledoit-Wolf
  收缩（方法名入结果）；窗口不足明确拒绝。
- 有效前沿：目标收益网格求最小方差，个别端点不可行如实跳过；前沿波动率单调
  （≥80% 点不降，容忍数值噪声）。
- 防过拟合：估计只用 ≤t（篡改 t 后数据权重不变的测试）；组合引擎 `weights="mvo"`
  模式**每次再平衡滚动重估**，权重在执行前计算完成；与等权/逆波动率同条件对比。
- 测试 14 个：约束满足、数学性质（最小方差≤等权方差）、不可行拒绝、前沿单调、
  因果性、回测集成与三方比较、历史不足回退等权。

## 四、调度器启动方式与生命周期

应用启动（任一页面首次加载）时 `Home.py` 内 `@st.cache_resource` 启动调度线程：
进程内单例（页面刷新/切换不重复启动）+ `scheduler_lease` 租约（心跳 30s 内续期、
90s 超时可被其他实例接管）→ 全局单实例。重启后：租约过期自动接管、调度配置从
`schedules` 表恢复、残留非终态任务由 `recover_stale_tasks` 标记失败（可重试）、
同一计划实例因 `schedule_id+planned_at` 唯一而不会重复执行（模拟订单不重复产生）。

## 五、模拟交易成交假设与限制

收盘价简化模型（最后已知收盘价±滑点，非实时、非下一开盘）；无杠杆无做空；
手续费比例+最低费简化。参考行情时间戳在订单与页面明示。**历史回测 ≠ 模拟账户
收益**，模拟成交 ≠ 真实市场成交。

## 六、PDF 字体配置与回退

优先 `data/fonts/`（用户放置授权字体）→ 系统 `simhei.ttf` 等 → ReportLab 内置
`STSong-Light`。全部失败时拒绝生成并提示 HTML/CSV 替代。matplotlib 图表中文
跟随同一字体源。

## 七、均值—方差估计假设与风险提示

历史均值/协方差估计对样本敏感（尤其预期收益）；满仓预算约束；Ledoit-Wolf 收缩
可选；**历史最优权重不代表未来表现**（页面与 PDF 均含此提示）；回测按再平衡日
滚动重估防前视。
